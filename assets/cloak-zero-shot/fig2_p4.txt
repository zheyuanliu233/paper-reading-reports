Figure 2: Overview. Cloak renders a geometric mask of the end-effector using the robot state andwrist camera parameters, augments it during training, and uses it to compute an attention mask forthe vision encoder, cloaking the end-effector from the wrist view. The resulting image patch tokens,the source-robot state, and the language prompt drive a single VLA backbone and action head. Onan unseen embodiment, tip-pose retargeting bridges the robots via FK and IK; trg2src maps thetarget state to the source state input to the policy; src2trg maps action outputs back to the target.
