如果你只有 5 分钟
  • 问题：FK/IK 可以处理 kinematic gap，但 wrist camera 中末端执行器占据固定大区域；换成新夹爪或五指手后，视觉 encoder 会严重 OOD。
  • 核心：从 URDF mesh、robot state 和 wrist-camera parameters 实时 rasterize 几何 mask，在 ViT attention 中阻止任何 token 读取被遮 patch。

TL;DR

论文主张Zero-shot cross-embodiment 的 binding constraint 不是 action interface，而是腕部视角中的 visual embodiment gap。Cloak 不用 segmentation/inpainting/generative model，而从已知 robot geometry 渲染 mask；训练时做 silhouette augmentation，测试时对任意新本体直接遮掉自身末端，再用 tip-pose retargeting 桥接 joint space。

我的解读这是“主动删除 shortcut”的方法。它不试图让 VLA 识别所有未来机械手，而是让视觉表示根本不接触这部分高变化、低任务信息的像素。代价是只保留 mask 外的环境证据，并把形态差异交给几何 retargeting。

1. 问题与动机

大规模 DROID 等数据主要来自平行夹爪，但部署硬件正在转向新夹爪、不同 arm、五指手。腕部相机固定在末端附近，执行器在每帧都大而稳定，ViT 很容易把它的颜色、轮廓、开合状态当作预测 action 的 shortcut。换本体后，即便 target tip trajectory 与 source 一样，image token 分布也已变了。

打个比方

教人通过挡风玻璃开车，但训练图像下方永远有同一款引擎盖。换车后道路没变，引擎盖却变了；模型若把引擎盖边缘当作距离尺，就会系统性误判。Cloak 直接把引擎盖区域从 attention 中拿走。

具体 gap：RDT2/LAP 等零样本工作仍保持相似平行夹爪外观；Mirage/robot repaint 要 inpaint 与 render source robot；Shadow 需预先知道 target；learned segmentation 对细结构和新本体不稳。Cloak 要求的不是 target data，而是部署 robot 的几何与相机参数。

2. 相关工作与位置

跨本体方法大致沿两条线发展：一条在 action/state 层做 token、latent、keypoint 或 IK retargeting；另一条在 image 层 repaint、inpaint、domain randomization 或 segmentation。Cloak 的判断是前者未处理 wrist visual gap，后者又过重或依赖 target。它把“视觉去本体化”和“几何动作 retargeting”组合，但不要求在训练时见过 target silhouette。

flowchart LR A[多本体 action representation] --> B[kinematic gap 缩小] C[repaint / inpaint target view] --> D[视觉 gap 缩小但重] E[target-aware silhouette] --> F[未知未来本体不可用] B --> G[Cloak] D --> G F --> G G --> H[geometry mask + augmentation + tip IK]

3. 方法总览

5. 方法详解

5.1 几何 mask

$$M=\operatorname{rasterize}\left(\bigcup_{l\in G}K\,[T^w_c(q)]^{-1}T^w_l(q)V_l\right)$$
是什么
论文式 (1)：FK 把每个 link mesh 放进 world，再用 camera inverse pose 和 intrinsics 投到 wrist image，rasterize 成二值 mask；随后轻微 dilation 吸收标定误差。
为什么不用 segmentation
robot geometry 与 state 已知，render 在新本体上仍精确、实时，不受外观和细指结构 domain shift 影响。
前提
需要正确 URDF/mesh、joint state、intrinsics 与 per-episode wrist extrinsics。

5.2 Mask augmentation：不让 mask 轮廓本身变成新 shortcut

$$\tilde M=\left(M\cup\bigcup_{i=1}^{N_+}C_i^+\right)\setminus\bigcup_{j=1}^{N_-}D_j^-$$
是什么
在 mask boundary 附加 1-2 个随机 capsule，再从内部挖掉 1-2 个随机 disk。
超参
capsule radius 12-16 px、length 32-64 px、tilt ±30°；disk radius 8-16 px。
直觉
模型见到的是 silhouette distribution，不是固定 Robotiq 轮廓；因此 target 不必在训练时已知。Sharpa 上 NoAug 65.1，完整 Cloak 81.8 progression。
$$\tilde I(h,w)=\begin{cases}I((h+\Delta_h)\bmod H,(w+\Delta_w)\bmod W),&(h,w)\in M\\I(h,w),&\text{otherwise}\end{cases}$$
是什么
从同一图像 roll 一块内容填进 source body 区域，$\Delta_h,\Delta_w\sim U[H/3,2H/3]$。
为什么仍要填像素
patch 过半才被 mask，边缘会漏 source pixels；disk removal 也会重新暴露内部。roll fill 比纯色/噪声更接近 scene distribution，又没有生成模型 hallucination。

5.3 在 attention 层真正“看不见”

$224\times224$ 图像按 $14\times14$ patch 切分，得到 256 个 patch。每个 patch 超过一半像素被 mask 时，$\tilde M^A_j=1$。

$$\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt d}+A\right)V,\quad A_{ij}=\begin{cases}-\infty,&\tilde M^A_j=1\\0,&\text{otherwise}\end{cases}$$
是什么
论文式 (4)。任何 query 都不能读取 masked patch 作为 key/value；token slot 保留，sequence length 不变。
传播
同一 mask 复用于所有 self-attention layer，并继续 gate VLA backbone 的 cross-modal attention。
范围
只 mask wrist view；论文发现 external camera 对 visual embodiment gap 贡献较小。

5.4 双向 tip-pose retargeting

$$(\hat T_l,\hat T_r)=FK(\hat q_{src}),\quad \hat q_{trg}=IK(\hat T_l,\hat T_r)$$
$$ (T_l,T_r)=FK(q_{trg}),\quad q_{src}=IK(T_l,T_r)$$
输出方向 src2trg
VLA 仍输出 source joint action；先得到 source 两 tip pose，再求 target joints。
输入方向 trg2src
把 target 当前两 tip pose 反解成 source joint state，让 policy 的 proprioception 仍在训练分布。
五指手
source 左右夹爪 tip 对应 target thumb 与 middle fingertip；scalar gripper signal 在线性插值的 open/closed hand pose 间控制。
稳定性
Mink weighted least squares 加 wrist orientation、damping、posture regularizer，避免 IK null-space 跳变。
视觉上把“我长什么样”删掉，动作上只保留“两枚工作指尖要到哪里”。

6. 走一遍例子

用从 Robotiq source policy 到 Sharpa hand 的 pick-and-place 举例。

  1. target observation：Sharpa 五指手 wrist image、external image、joint state 与 prompt “Place the block in the bowl”。
  2. 视觉去本体：Sharpa URDF + joints 渲染五指 mask；测试时不增强，ViT 对这些 patch 的 attention key 加 $-\infty$。
  3. state 转换：Sharpa thumb/middle tip 经 FK 得到 $T_l,T_r$，再用 source IK 求一个等价 Robotiq/Franka $q_{src}$。
  4. source policy：Cloak-VLA 只看到环境 patch、external view、语言与 source-space state，输出 source joint action chunk。
  5. action 转换：source FK 得 tip targets，Sharpa IK 求 arm joints；gripper scalar 映射到 hand open/closed interpolation，执行后进入下一闭环 step。

7. 实验

训练：DROID 单一本体（Franka + Robotiq 2F-85），约 75K episodes / 350h；论文数据过滤后约 70K train episodes。Cloak-VLA 从 $\pi_{0.5}$ fine-tune 100K steps，约 1 epoch，8 H100 用 48 小时。

评测：Pick and Place、Remove、Move、Fold/Unfold；每任务 12 个固定随机 instance，每本体 48 trials，单 trial 最长 60 秒。主要指标 progression rate，另报 binary success rate。

9. 局限与讨论

  • 作者承认：只覆盖可由两个 fingertip pose 表达的 manipulation，不覆盖丰富接触策略、in-hand reorientation 等真正 dexterous skill。
  • 行为上限：policy 继承 DROID gripper-style tabletop data 的行为，不会因换成五指手自动学会多指能力。
  • IK 取舍：为稳定 null-space 加的 orientation/posture regularizer 会抑制某些任务本来有益的 wrist tilting。
  • 迁移非无损：Sharpa progression 由 source 88.0 降到 81.8；论文建议把 body-agnostic checkpoint 当作 few-shot/continual learning 起点。
  • camera 约束：Sharpa mount 特意让 fingers 落在与 source 类似的图像区域；mask 去除外观，但不自动解决视角、FOV 或 scene occlusion 的大变化。
  • 数据处理成本：DROID 原 wrist extrinsics 不够精确，作者为每 episode 做 Silhouette Calibration；过滤 failure 22%、extrinsic outlier 约 1.7%，再留 5% validation。
  • 资源状态：官方仓库只开放 calibrated DROID wrist extrinsics 与预处理脚本，README 写明训练代码和 checkpoint “coming soon”。

10. 常见疑问

直接把 mask 区域涂黑不行吗？

黑色本身会成为新视觉 token；边缘 patch 还会泄漏 source pixels。Cloak 用 attention bias 真正阻断读取，并用 rolled scene content 处理泄漏路径。

训练增强 mask，测试为什么不增强？

训练增强的目标是让 encoder 对 silhouette 不敏感；测试已知 target geometry 时，精确 mask 能最大限度保留环境信息，不需要额外随机遮挡。

它和 camera-frame action 是替代关系吗？

不是。Camera frame 对齐动作的几何语义；Cloak 删除腕部图像中的本体外观，并用 tip IK 桥接 joint space。两者分别处理 motion gap 与 visual gap。

它是 zero-shot 吗？

对 target data 和参数更新而言是：target 在训练中未见、无 target demonstration、无 retraining。但部署仍需要 target URDF/mesh、camera parameters、joint state、两 tip 定义与可工作的 IK。

训练代码发布后的实现核对清单

  1. 确认 wrist extrinsics 的方向是 camera pose relative to end-effector，并与 MuJoCo attachment site 一致。
  2. 只用 successful DROID episodes，复现 1% extrinsic outlier filtering 和 5% validation split。
  3. 离线存 source mask；在线按 Appendix B.1 执行 roll fill、1-2 capsules、1-2 disks。
  4. 将 majority-vote 256D patch mask 注入所有 ViT self-attention，并 gate 下游 cross-modal attention。
  5. 用 Mink 同时实现 src2trg/trg2src，逐 action-chunk step 求 IK；先在 source 做 round-trip FK/IK 误差测试，再接 target hardware。
安全与工程坑

IK null-space jump、错误 tip frame、mask dilation 不足、camera calibration 漂移和硬件不可达都可能产生危险命令。论文实验会在有损坏风险时提前终止；实机复现应设置 workspace、velocity、collision 与 emergency-stop 限制。

12. 术语表

Embodiment
机器人身体配置，包括 arm、end-effector、joint topology 与 camera mounting。
Visual embodiment gap
更换本体后，robot 自身在图像中的外观造成的 observation distribution shift。
Attention mask
在 softmax 前给特定 key 加 $-\infty$，使其不被任何 query 读取。
Tip-pose retargeting
以一组共同工作点的 6DoF pose 为桥，在 source/target joint space 间用 FK/IK 转换。
Silhouette Calibration
用伪真值 mask 与 simulation render 的 IoU 优化 wrist extrinsics。
Progression rate
完成的最高有序子阶段占总阶段比例；允许对接近成功的 rollout 给 partial credit。
